# 小樽商大履修支援サイト

小樽商科大学の履修計画・シラバス確認を補助する、個人制作の非公式ツールです。大学公式サービスではありません。

## 注意

- 履修登録、卒業要件、開講情報などの最終確認は、大学公式資料・Campus Square・manaba・教務課等を優先してください。
- 卒業要件判定は、対象年度のカリキュラムに通常入学し、標準的な履修を行っている学生を主対象としています。
- 編入学・再入学・転科・留学・交換留学・他大学との単位互換・特殊な単位認定・教職課程等の資格課程・旧カリキュラムや経過措置など、個別の取扱いがある場合は卒業判定機能の利用を推奨しません。

## 権利について

本リポジトリのプログラムコードと、小樽商科大学が作成・公開しているシラバス、履修資料その他の大学由来データは別のものです。
大学由来の資料・文章・データについて、その権利が本リポジトリの作者に帰属することを意味しません。

## 公開

GitHub Pages での公開を想定した静的サイトです。
